TapeLog AI Coach: a free AI trade-journal coach for Claude, ChatGPT & Cursor

Point your AI assistant at your DAS Trader Pro or Robinhood export and ask how you actually traded. TapeLog is an open-source MCP server. It rebuilds your round trips locally, calculates your stats, and describes the patterns in your own behavior.

Install (Claude Desktop, Cursor, other MCP clients)

Install uv, then add this to claude_desktop_config.json or ~/.cursor/mcp.json:

{
  "mcpServers": {
    "tapelog": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/tapelog-journal/tapelog-mcp", "tapelog-mcp"]
    }
  }
}

Claude Code: claude mcp add tapelog -- uvx --from git+https://github.com/tapelog-journal/tapelog-mcp tapelog-mcp

For AI agents: pay-per-report API

Agents can get the weekly habit report over HTTP with no account and no API key. Send the trader's own broker CSV (DAS Trader, Robinhood or generic) as the raw body of POST https://tapelog-api.tapelog.workers.dev/habit-report with Content-Type: text/csv. The API answers 402 Payment Required with x402 v2 payment terms: $0.10 USDC per report on Base (eip155:8453). Any x402 client signs the payment and retries to get the report as JSON or Markdown. Invalid CSVs are rejected with 400 before any payment is asked for, and nothing is stored.

Endpoint details: https://tapelog-api.tapelog.workers.dev/ (free, JSON). Source and docs: tapelog-api on GitHub (MIT).

FAQ

What is the TapeLog AI Coach?

A free, open-source (MIT) MCP server and prompt pack that lets Claude, ChatGPT, Cursor and other AI assistants analyze your own DAS Trader Pro or Robinhood CSV exports: win rate, profit factor, expectancy, drawdown, PDT day-trade count, and descriptive breakdowns of where your results were weakest.

Is my trading data uploaded anywhere?

The MCP server runs on your own computer and stores fills in ~/.tapelog/fills.json. There is no broker login and no TapeLog cloud. Your AI client sees the tool results you ask for, under that client's own privacy terms.

Does it tell me what to trade?

No. TapeLog only describes your own past trades and process, such as timing, sizing, hold times and discipline. It never recommends buying, selling or holding any security and gives no price targets, signals, picks or market predictions. It is educational and record-keeping software, not investment advice, and TapeLog is not a registered investment adviser.

Which AI apps does it work with?

Any MCP client: Claude Desktop, Claude Code, Cursor, Windsurf, VS Code, Cline and others. With no MCP client, paste the TapeLog Coach instructions into a ChatGPT Custom GPT or a Claude Project and upload your CSV.

Which brokers are supported?

DAS Trader Pro (Trades window CSV), Robinhood (Account activity report CSV), and any broker whose fills you can save as date, time, symbol, side, qty, price, fees.
