How to export trades from DAS Trader Pro

DAS Trader Pro has no built-in journal, but its Trades window can be exported to CSV.

Steps

  1. Open the Trades window in DAS Trader Pro (it lists today's executions).
  2. Right-click inside the window and choose the export option to save the trades as a CSV file.
  3. Save it with the date in the filename (e.g. das-2026-10-16.csv). The window holds one day and the file has no date column.
  4. Repeat at the end of each trading day.

What's in the file

Typical columns: Time, Symb, Side, Price, Qty, plus fee columns such as EcnFees. Side codes are B (buy), S (sell), SS (short sell) and BC (buy to cover). Exact columns can vary by broker and DAS configuration.

Turning fills into trades

Each row is a fill, not a trade. Group fills by symbol and running position: a trade starts when the position leaves zero and ends when it returns to zero. The full spreadsheet method is here, or paste the CSV into TapeLog's DAS import and it does the grouping for you.

Can't find older days? Your broker's own statements or trade-confirmation reports are the official record; ask them for a CSV of executions.

FAQ

Can DAS Trader Pro export trades?

Yes. Right-click the Trades window and export to CSV. It contains that day's executions.

Why is there no date in the DAS export?

The Trades window holds the current day only, so add the date yourself when you save or import the file.

What do SS and BC mean in DAS?

SS is a short sell and BC is a buy to cover a short.
